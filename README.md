# expo-doctor-appointment

React Native + Expo + TypeScript doctor appointment booking app. Doctor listing, profile view, calendar-based time slot booking, appointment history with cancel.

## Stack
- React Native + Expo + TypeScript
- Zustand (state management)
- Expo Router (navigation)
- react-native-calendars (date picker)
- Clean Architecture

## Features
- Doctor profile listing with specialty, rating, fee
- Search/filter doctors
- Calendar-based appointment booking with time slot selection
- Appointment history with status and cancel
- iOS + Android

## Run
```
npm install
npx expo start
```
